Sailfish OS

Askare

A native Nextcloud Tasks client for Sailfish OS - the lists of the server you already run, on the phone and over CalDAV.

Documentation GitHub
Releases Donate

What you can do

  • Sign in on the server's own page, with single sign-on and two factors
  • Every task list, plus the All, Current and Completed views
  • Dates, priority and completion on each task
  • Subtasks, counted on the row of their parent
  • Notes written in Markdown
  • A reminder before a task is due

Askare is free software under the GPL-3.0.
